## CT5-V Standard Performance Overview

**3.0L Twin-Turbocharged V6 Engine:**
The CT5-V delivers impressive performance with a 3.0L twin-turbocharged V6 engine producing 360 HP and 550 Nm of torque. This engine provides excellent balance between daily usability and track performance with advanced turbocharging technology.

## Driver Modes

**TOUR:** The default mode for everyday driving, providing precise handling and a smooth ride optimized for comfort during daily commuting while maintaining performance character.

**MY MODE:** Allows the driver to set their own preferences for steering feel, engine sound characteristics, and brake-pedal response for completely personalized driving experience.

**SNOW/ICE:** Optimizes performance and traction on slippery roads to prevent wheelslip with adjusted throttle response and stability control settings.

**SPORT:** Provides a more spirited driving experience with firmer steering, dynamic braking, and aggressive throttle response for enhanced track-focused performance.
